# UA Forever Translator

Перекладач ігрового чату для **World of Warcraft: Forever 1.60.1**. Показує український переклад підтримуваних англійських повідомлень поруч з оригіналом і готує чернетки англійською з українського тексту. Аддон працює локально й не потребує інших аддонів.

**English:** Offline English–Ukrainian chat translation and editable English drafts for WoW Forever. The addon uses a built-in dictionary and grammar patterns for common game chat. [CurseForge project description](CURSEFORGE.md)

## Встановлення

Помістіть файли цього репозиторію в папку `World of Warcraft/_forever_/Interface/AddOns/UA_Forever_Translator/`. Файл `UA_Forever_Translator.toc` має лежати безпосередньо в ній. Увімкніть аддон у грі. Для оновлення вже встановленого аддона скористайтеся `/reload`.

## Команди

| Команда | Дія |
| --- | --- |
| `/uaft` | Відкрити вікно чернетки |
| `/uaft en <фраза>` | Підготувати англійську чернетку |
| `/uaft lookup <термін>` | Знайти термін у словнику |
| `/uaft config` | Відкрити сторінку налаштувань аддона |
| `/uaft on`, `/uaft off` | Увімкнути або вимкнути переклад чату |

Канали та вигляд перекладу можна вибрати в **Налаштування → Додатки → UA Forever Translator**. Для загального й торгового чату увімкніть **Публічні канали (загальний, торгівля тощо)**. Цей прапорець за замовчуванням вимкнений.

У вікні чернетки можна перевірити й відредагувати переклад. Натисніть **Обрати поточний чат**, а потім **Вставити в чат**. Для часткової чернетки підтвердьте, що її переглянули. Надсилання виконує гравець.

Перекладач підтримує, наприклад, `LFM healer`, `Я це нідаю` та ігрові запрошення. Незнайомі частини залишаються видимими, а дослівна підказка має позначку «частково». Налаштування зберігаються локально. Аддон не записує історію повідомлень у свої SavedVariables і не звертається до зовнішніх сервісів.

Поза ігровими шаблонами аддон підставляє словникові відповідники в обох напрямках. Словники розпізнають також поширені словоформи. Для англійського слова в чаті показується один словниковий відповідник. В англійській чернетці варіанти можуть бути розділені `/`. Перегляньте чернетку, щоб вибрати значення й узгодити граматику.

## Розробка

Перший знімок має версію **0.1.0**. Окремі фрази проганялися через Lua-рушій. Повний прогін тестів і сумісність у грі ще не підтверджені.

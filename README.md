# UA Forever Translator

Перекладач ігрового чату для **World of Warcraft: Forever 1.60.1**. Показує український переклад в окремій вкладці **UA** і готує англійські чернетки з українського тексту. Звичайні вкладки чату показують оригінальні повідомлення. Аддон працює локально й не потребує інших аддонів.

**English:** Offline English–Ukrainian chat translation and editable English drafts for WoW Forever. The addon uses a built-in dictionary and grammar patterns for common game chat. [CurseForge project description](CURSEFORGE.md)

## Встановлення

Помістіть файли цього репозиторію в папку `World of Warcraft/_forever_/Interface/AddOns/UA_Forever_Translator/`. Файл `UA_Forever_Translator.toc` має лежати безпосередньо в ній. Увімкніть аддон у грі. Для оновлення вже встановленого аддона скористайтеся `/reload`.

## Команди

| Команда | Дія |
| --- | --- |
| `/uaft` | Відкрити вікно чернетки |
| `/uaft en <фраза>` | Підготувати англійську чернетку |
| `/uaft lookup <термін>` | Знайти термін у словнику |
| `/uaft config` | Відкрити сторінку налаштувань аддона |
| `/uaft tab` | Перейти до вкладки UA або відкрити її після закриття |
| `/uaft on`, `/uaft off` | Увімкнути або вимкнути переклад чату |

Вкладка **UA** з’являється після входу у світ, якщо переклад увімкнено й у панелі WoW є вільне місце. Якщо всі вкладки зайняті, звільніть одну та введіть `/uaft tab`.

Канали для перекладу можна вибрати в **Налаштування → Додатки → UA Forever Translator**. Для загального й торгового чату увімкніть **Публічні канали (загальний, торгівля тощо)**. Для повідомлень `/say` і `/yell` увімкніть **Сказати й крикнути**. Обидва прапорці за замовчуванням вимкнені.

Введіть український текст у верхньому полі й натисніть **Перекласти**. За потреби відредагуйте англійський текст у нижньому полі. Позначте **Say**, **Group**, **Yell** або **Current** і натисніть **Вставити в чат**. Аддон відкриє відповідний рядок із перекладом. Надсилання виконує гравець.

Перекладач підтримує, наприклад, `LFM healer`, `Я це нідаю` та ігрові запрошення. Незнайомі частини залишаються видимими, а дослівна підказка має позначку «частково». Налаштування зберігаються локально.

У чаті розпізнаються, зокрема, `PST`, `LFW`, `OBO`, `pat inc`, `2SR` та `MS>OS`. Значення багатозначних скорочень можна подивитися через `/uaft lookup BoP` або `/uaft lookup HR`. У фразах на кшталт `BoP item` і `BoP me` переклад враховує сусідні слова.

Поза ігровими шаблонами аддон підставляє словникові відповідники в обох напрямках. Словники розпізнають також поширені словоформи. Для англійського слова в чаті показується один словниковий відповідник. В англійській чернетці варіанти можуть бути розділені `/`. Перегляньте чернетку, щоб вибрати значення й узгодити граматику.

## Журнал перекладів

У `/uaft config` є прапорець **Записувати оригінали й переклади в локальний журнал**. За замовчуванням він вимкнений. Після ввімкнення журнал записує обидва напрямки: **EN → UK** після показу перекладу у вкладці **UA** та **UK → EN** після успішного показу англійської чернетки в композері, зокрема через `/uaft en`. Зберігаються оригінал, переклад, режим, подія й `direction` (`en-uk` або `uk-en`). Вхідний запис охоплює всі ввімкнені канали, включно з приватними повідомленнями. Подія `COMPOSER_PREVIEW` означає показ чернетки, а не її надсилання. Повні й часткові переклади записуються; невдалі покази та текст без перекладу — ні.

Після `/reload` або виходу з гри записи доступні в таблиці `UA_Forever_TranslatorLog` у файлі `WTF/Account/<обліковий запис>/<сервер>/<персонаж>/SavedVariables/UA_Forever_Translator.lua` всередині папки `_forever_`. Кількість записів **не обмежена**: `entries` зберігає пари від найдавнішої до найновішої, а `nextIndex` вказує на наступне вільне місце. Під час першого нового запису старий кільцевий журнал переноситься в `schema=2` зі збереженням наявних пар та їхнього порядку. Вимкнення прапорця зупиняє нові записи й залишає збережену історію.
